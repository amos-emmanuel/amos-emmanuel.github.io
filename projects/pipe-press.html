Hydraulic Pipe Press / Straightener

Independent · OpenSCAD
Add a hero image at assets/projects/pipe-press.jpg

A fully parametric model of a hydraulic pipe press and straightener, built in OpenSCAD so the core dimensions — pipe diameter, stroke length, frame geometry — are driven by variables rather than hand-redrawn for each size variant.

The viewer below loads STL exports directly — drag to orbit, scroll to zoom. The demo part shown is a placeholder; swap in the real exported part with the loader below.

demo_bracket.stl
drag to orbit · scroll to zoom

Export from OpenSCAD via File → Export → Export as STL. Native .scad files can't render in-browser.
