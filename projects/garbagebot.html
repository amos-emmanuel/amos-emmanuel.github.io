Garbagebot — Autonomous Trash Collection in Simulation

Team of four · Case Western Reserve University · CoppeliaSim, Python, Lua
Add a hero image at assets/projects/garbagebot.jpg

A simulated autonomous mobile robot built in CoppeliaSim that patrols an environment, detects red blocks as trash via a downward-facing camera, avoids static and moving obstacles using LiDAR, and picks up detected trash with a manipulator arm.

My work focused on the robot modeling and integration into CoppeliaSim — building the platform, mounting the sensors, and wiring the simulation-side scripts so the perception, planning, and manipulation stacks could talk to each other. I also worked on the manipulation side: the arm control loop that positions the end-effector over a detected block and closes on it.

The project split cleanly between behaviors that live in different loops: LiDAR obstacle avoidance runs continuously as a low-level driving reflex, while the vision-triggered trash pickup runs as a higher-level state machine that pauses navigation, executes a grasp sequence, and resumes patrol. Making those two loops share the same robot cleanly without deadlocking or fighting each other was the interesting integration problem.
