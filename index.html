PROJECT 01

EKF Magnetic Signature Navigation

Senior Capstone · State Estimation · MATLAB

A bio-inspired agent navigates a simulated North Atlantic using Earth’s magnetic signature (intensity + inclination). The catch: secular variation slowly drifts the field, so a fixed location’s signature changes over time. I integrated an Extended Kalman Filter that predicts how each goal’s signature evolves between migrations and corrects itself on arrival — successfully completing 250 migration cycles under translation, rotation, and combined field change.

PROJECT 02

Geothermal CO₂ Sequestration Power Cycle

Thermofluids (EMAE 355) · Python · CoolProp

Designed a closed-loop power cycle that uses CO₂ as both sequestration fluid and working fluid, circulating it through a 3.2 km saline aquifer at 224 °C to drive a turbine and offset pump power. I built a quasi-1D well model (Churchill friction, Gnielinski/Dittus–Boelter Nusselt, NTU-ε heat transfer, Darcy’s law) and a 2D optimizer sweeping pressure and mass flow to maximize net work, with thermodynamically correct P–h diagrams.

Repositories & explanations

The engineering behind the projects — with enough context to understand what each one actually does.

ekf-magnetic-navigation
MATLAB · capstone

An Extended Kalman Filter built from scratch to track and predict a nonlinear, time-varying magnetic signature. The core idea: the standard Kalman filter assumes linear dynamics, but magnetic signatures drift nonlinearly under secular variation. The EKF linearizes around the current estimate at each step — predict the goal’s next signature from a motion model, then correct using the measured signature when the agent reaches the goal, weighted by the Kalman gain. A key debugging win: fixing a measurement model that ignored its state input and was silently zeroing the Kalman gain.

geothermal-co2-cycle
Python · thermofluids

A physics-based simulation of a closed-loop geothermal CO₂ power cycle. It models the full loop segment-by-segment: a quasi-1D well model with Churchill friction factors and Gnielinski/Dittus–Boelter Nusselt numbers, composite cylindrical wall resistance, NTU-ε heat transfer in the wells and aquifer, and Darcy’s law for aquifer pressure drop. All CO₂ properties come from CoolProp, and a 2D optimizer sweeps high-side pressure and circulation mass flow to maximize net work — then plots a thermodynamically correct P–h diagram.
